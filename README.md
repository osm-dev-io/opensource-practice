# Open Source Practice

[인프런 오픈소스 챌린지](https://www.inflearn.com/challenge/highly-recommended-f?cid=344265)의 실습을 위한 저장소입니다.

![인프런 오픈소스 챌린지 소개 이미지](assets/inflearn-opensource-challenge.png)

## 실행 방법

### GitHub Pages로 실행하기

[공개 사이트](https://osm-dev-io.github.io/opensource-practice/)에 접속합니다.

### 로컬에서 실행하기

1. 터미널에서 저장소를 복제합니다.

```bash
git clone https://github.com/osm-dev-io/opensource-practice.git
```

2. 복제된 `opensource-practice` 폴더를 엽니다.
3. `src/index.html`을 브라우저에서 엽니다.

## 기여하기

issues와 PR은 언제나 환영입니다! 자세한 기여 방법은 [CONTRIBUTING.md](CONTRIBUTING.md) 파일을 참고해 주세요.
